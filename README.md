## Project Showcase

Interactive **Student Report Card System** and **Student Report Grading System** built with HTML, CSS, Bootstrap, and JavaScript. Enter student name, roll number, and marks to calculate grades — a university web development lab project.

## Repository

[github.com/mafzalkalwardev/student-report-card-system](https://github.com/mafzalkalwardev/student-report-card-system)

## Key Features

- Student name and roll number input
- Marks entry with automatic grade calculation
- Bootstrap 4 responsive UI
- Report card display with styling
- Separate grading form variant (`form.html`)

## Quick Start

Open `index.html` or `form.html` in any modern browser.
